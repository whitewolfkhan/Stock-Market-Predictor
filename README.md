# 📈 Stock Market Predictor

A Python project that predicts **future stock price trends** using **machine learning** and **historical stock data**.  
It leverages **pandas**, **scikit-learn**, and **yfinance** to fetch data, train a model, and visualize results.

---

## 🚀 Features
- 📊 Fetches real-time or historical stock data from **Yahoo Finance**
- 🧹 Cleans and preprocesses data automatically
- 🧠 Uses a **Random Forest Regressor** to predict stock closing prices
- 📈 Plots actual vs predicted values with **matplotlib**
- ⚙️ Easy to extend with more indicators or deep learning (LSTM, etc.)

---

## 🧰 Tech Stack
| Library | Purpose |
|----------|----------|
| **pandas** | Data cleaning and manipulation |
| **numpy** | Numerical computation |
| **scikit-learn** | Machine learning model |
| **matplotlib** | Data visualization |
| **yfinance** | Stock data fetching |
